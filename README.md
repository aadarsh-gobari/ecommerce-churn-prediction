# E-commerce Customer Churn Prediction

A production-level data science project to predict customer churn for an e-commerce business using machine learning.

## Project Structure
- `data/` — raw and processed datasets
- `notebooks/` — exploratory analysis and modeling notebooks
- `src/` — reusable Python modules
- `models/` — saved trained models
- `reports/` — charts, figures, and final report

## Setup
```bash
pip install -r requirements.txt
```

## Tech Stack
Python, Pandas, Scikit-learn, XGBoost, MLflow, Seaborn
